# Хряк (Jarvis) — голосовой ассистент для Windows

Локальный ассистент в стиле Джарвиса: слушает микрофон, ждёт слово **«Хряк»**,
выполняет команды и отвечает живым нейроголосом.

Распознавание гибридное: Vosk ловит wake-word и конец фразы, а саму команду
уточняет **GigaAM v3** — заметно точнее на именах и падежах.

## Готовое приложение для Windows

Не хочется ставить Python и качать модели? Возьмите готовую сборку:

**[Hryak-Windows-x64.zip](https://github.com/artemmvs2-stack/hryak/releases/latest)** (~450 МБ)

1. Распакуйте архив в любую папку, например `C:\Hryak`.
2. Запустите `Hryak.exe`.

Внутри уже есть Python, Vosk, GigaAM и голос Piper — устанавливать ничего не
нужно. При первом запуске рядом с `Hryak.exe` появится `config.json`; для
ответов LLM впишите туда свой `llm.api_key`. Журнал — в `logs\jarvis.log`.

При первом запуске SmartScreen может показать «Windows защитила ваш
компьютер»: нажмите «Подробнее» → «Выполнить в любом случае». Сборка не
подписана сертификатом, это нормально.

## Установка из исходников

Нужен **Windows 10/11** и **Python 3.10+**.

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

1. Скачайте модель Vosk **vosk-model-small-ru-0.22** с
   [alphacephei.com/vosk/models](https://alphacephei.com/vosk/models) и
   распакуйте её в `models\vosk-model-small-ru-0.22`.
2. Скачайте голос Piper `ru_RU-denis-medium.onnx` и файл
   `ru_RU-denis-medium.onnx.json` из репозитория
   [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) и
   положите их в `models\piper`.
3. Скопируйте `config.example.json` в `config.json` и при желании заполните
   `llm.api_key` (без ключа работают все локальные команды).
4. Запустите `run.bat`.

Для более точного распознавания команд можно подключить GigaAM:

```bat
python -m venv venv_gigaam
venv_gigaam\Scripts\activate
pip install -r requirements-gigaam.txt
```

Затем в `config.json` поставьте `"stt_engine": "gigaam"` и
`"gigaam": {"enabled": true}`. Модель скачается автоматически при первом
запуске. Офлайн-голос Silero ставится отдельно:
`pip install -r requirements-silero.txt`.

## Как запустить

| Способ | Что делает |
|---|---|
| `run.bat` | запуск с окном консоли (видно журнал) |
| `run_silent.vbs` | запуск без окна, иконка в трее |
| `tools\install.py` | автозапуск при входе в Windows + ярлык на рабочем столе |

Иконка в трее (бирюзовый круг): **Слушать**, **Остановить речь**, **Журнал**,
**Автозапуск**, **Выход**.

## Как пользоваться

1. Скажите: **«Хряк»**. Сигнала нет — просто говорите команду.
2. Сразу после активации — команду: **«Хряк, открой браузер»**.
3. Дальше **30 секунд** можно говорить команды без «Хряк»: ассистент
   продолжает слушать. Каждая новая команда продлевает это окно.
   Если долго молчать, он снова начинает ждать слово «Хряк».

## Настройка LLM

Скопируйте `config.example.json` в `config.json` (этот файл не попадает в git)
и заполните:

```json
"llm": {
  "base_url": "https://api.deepseek.com/v1",
  "api_key": "sk-...",
  "model": "deepseek-chat"
}
```

Подходит любой OpenAI-совместимый провайдер (DeepSeek, OpenAI, OpenRouter,
локальный LM Studio/Ollama с `/v1`). Без ключа ассистент выполняет только команды.

Другие полезные поля: `voice` (голос edge-tts), `voice_rate`, `city`,
`silence_timeout`, `wake_words`, `followup_seconds`, `beep`.

- `followup_seconds` — сколько секунд после команды слушать без «Хряк»
  (по умолчанию 30; `0` отключает режим диалога).
- `followup_allow_llm` — разрешать в режиме диалога свободные вопросы к
  GPT без повторного «Хряк» (по умолчанию `false`: без обращения
  выполняются только обычные команды, фоновый разговор не уходит в GPT).
- `beep` — звуковой сигнал при активации (`false` — без писка).
- `search_engine` — поисковик по умолчанию: `yandex`, `google`, `bing`
  или `duckduckgo`.

### ИИ-управление компьютером

Если модель поддерживает OpenAI tool calling, Хряк выполняет действия по
свободной формулировке: «открой блокнот и напечатай привет», «включи видео
котиков», «сверни все окна», «поставь громкость 30», «сделай скриншот».
Модель сама выбирает инструмент, получает результат и только потом отвечает.

```json
"llm": {
  "computer_control": true,
  "tool_rounds": 3
}
```

- `computer_control` — разрешить ИИ управлять компьютером (по умолчанию `true`).
- `tool_rounds` — сколько шагов с инструментами разрешено за один запрос.

Инструменты работают только после обращения «Хряк» и только по белому списку:
программы, сайты, браузер, окна, громкость, медиа, буфер обмена, печать текста,
скриншоты, папки, заметки, напоминания, состояние системы, калькулятор и
яркость. Выключение и перезагрузка компьютера в этот список не входят — это
отдельные голосовые команды с 15-секундной отменой. Если API не поддерживает
инструменты, ассистент автоматически возвращается к обычному текстовому режиму.

### Голос

По умолчанию используется **Piper** — офлайн-нейроголос «Денис», работает без
интернета и без лимитов. Голос задаётся в `config.json` → `piper.voice`:

| Значение | Голос |
|---|---|
| `denis` | мужской (по умолчанию) |
| `ruslan` | мужской |
| `irina` | женский |

`tts_engine` задаёт основной движок: `piper`, `edge` или `silero`.
Порядок отката: Piper → edge-tts → Silero → SAPI «Ирина».
Проверить голоса: `venv\Scripts\python.exe tools\silero_demo.py`.

### Распознавание речи

- **Vosk** (`models/vosk-model-small-ru-0.22`) слушает постоянно, находит
  wake-word «хряк» и определяет, когда фраза закончилась.
- **GigaAM v3 E2E CTC** (`models/gigaam_e2e`, ONNX int8) распознаёт саму
  команду из записанного WAV. В исходной версии модель живёт в отдельном
  окружении `venv_gigaam`, в портативной — во встроенном Python.
- Если GigaAM ещё загружается или упала, команда выполняется по тексту Vosk.
  Ничего не ломается — просто точность ниже.

Настройки в `config.json`:

```json
"stt_engine": "gigaam",
"gigaam": {
  "enabled": true,
  "model": "gigaam-v3-e2e-ctc",
  "quantization": "int8",
  "download_root": "models/gigaam_e2e",
  "timeout": 10,
  "pre_roll_seconds": 3.0
}
```

Чтобы вернуться на чистый Vosk, поставьте `"stt_engine": "vosk"`.
Последние 40 записанных команд лежат в `data\stt` — их удобно проверять
обеими моделями.

venv\Scripts\python.exe tools\audio_test.py
venv\Scripts\python.exe tools\selftest.py

## Сборка портативного приложения

Готовый `Hryak.exe` собирается скриптом (нужны интернет, .NET Framework 4.x
и установленные зависимости из `requirements.txt`):

```bat
build_windows.bat
```

Скрипт скачает embeddable Python 3.12, поставит зависимости без torch,
соберёт папку `build_portable\Hryak`, скомпилирует `Hryak.exe` с иконкой и
упакует всё в `dist\Hryak-Windows-x64.zip`. Модели Vosk, GigaAM и Piper
берутся из локальной папки `models`.

Лицензии сторонних компонентов перечислены в
[packaging/THIRD_PARTY_NOTICES.md](packaging/THIRD_PARTY_NOTICES.md).
